REPOSITORY TOWN — offline copies (188 houses)

Double-click an HTML file to play in your browser. No internet, server or Claude needed
(links to GitHub and live sites need internet, of course).

  Repository-Town.html              THE MAIN ONE. Every house shows its real repository name,
                                    and every house has a Repository Archive room you can
                                    explore: README, file browser, docs, live site, latest
                                    commit, lucky-dip file, README fortune and a dice tray.
                                    It contains your private repositories' names and READMEs,
                                    so keep it to yourself.
  Repository-Town-public-safe.html  Private repositories show as "Private house" with no
                                    names or README text. Only this one is safe to put on a
                                    public website.

Controls
  Computer: WASD/arrows move, drag mouse to look (double-click locks the pointer),
            Shift run, C crouch, Space jump, E use an exhibit, M bird's-eye map.
  Phone:    left thumb joystick, right thumb drag to look, ✋ use, ⤒ jump, 🏃 run, 🧎 crouch.
  Walk up to a front door to go in; walk back out the same door. Search by name or "B2".
  Exhibits with buttons (dice, cards, arcade, lucky dip) can be used again and again.
