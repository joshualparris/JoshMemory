REPOSITORY TOWN — offline copies (188 houses)

Double-click either HTML file to play in your browser. No internet, server or Claude needed.

  Repository-Town-private.html  Full detail, including your private repositories.
                                Keep this one to yourself.
  Repository-Town-public.html   Private repositories show as "Private house" with no names.
                                This is the one that is safe to put on a public website.

Controls
  Computer: WASD/arrows move, drag mouse to look (double-click locks the pointer),
            Shift run, C crouch, Space jump, E use an exhibit, M bird's-eye map.
  Phone:    left thumb joystick, right thumb drag to look, buttons for use/jump/run/crouch.
  Walk up to a front door to go in; walk back out the same door. Search by name or "B2".

To publish on a website: upload Repository-Town-public.html (rename it index.html)
to any static host — Vercel, Netlify or GitHub Pages.
