## How each house was tested

Automated, real rendering: Playwright drove headless Chromium with WebGL (SwiftShader software GPU) against the built game.
For every house, on a 1100×700 desktop viewport with the keyboard **and** on an emulated Pixel 7 with touch input (joystick drag and the ✋ button):
1. travel to the street outside the house;
2. walk forward until the front door swings open and the player enters through it (no teleport);
3. for every exhibit: stand in front of it, confirm the game prompts for it, use it, and check its effect (panel content, quiz answer, toggle state, link);
4. walk back out of the front door.

Movement mechanics checked once per run — run: true, crouch: true, jump: true, wall collision: true, autosave survives reload: true.

Every house also has a generated Repository Archive (source, README, file browser, live site, latest commit, docs, lucky dip, README fortune, dice tray and a resident to talk to), and game houses an Arcade. All of these are exercised by the same per-house walk.

Playable games: 59 of 59 packed games load from file:// without errors (tests/games.mjs).

**Not covered:** Groq replies were tested against a stand-in server (this environment cannot reach api.groq.com); no test ran on a physical Android phone or a hardware GPU; frame rate on real devices is unmeasured; audio output was not listened to.
