# Heritage house references

Four public-only, house-museum interpretations are planned for A3, N3, T2 and I7. The memorial at C2 must remain unchanged. No private repository URL or README belongs in the published replacement houses.

| Lot | Public title | Historical museum source |
| --- | --- | --- |
| A3 | Elizabeth Farm | https://mhnsw.au/visit-us/elizabeth-farm/ |
| N3 | Monticello | https://www.monticello.org/what-is-monticello/an-iconic-house/rooms-furnishings |
| T2 | Vaucluse House | https://mhnsw.au/visit-us/vaucluse-house/plan-your-visit/ |
| I7 | Fallingwater | https://franklloydwright.org/site/fallingwater/ |

These are small, original, schematic representations rather than architecturally exact replicas. Resident interpreters are fictional, not representations of living private individuals.
