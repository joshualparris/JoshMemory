# Narromine Street View review links (for Josh)

Open each link, look at the real street (left) against the game (right), and note anything that
differs: a missing or extra building, wrong roof, wrong colour, missing tree, sign or fence. Send the
notes back and each one becomes a numbered item in `NARROMINE_REALISM_TODO.md`.

Google's terms allow viewing Street View live, but not storing or analysing its images, so these
checks are done by eye only. Each link opens the compare page at the same spot and heading.

Base: https://repository-town-claude-complete.vercel.app/narromine-compare.html
