# The Merged Branch — fictional history (1911–2026)

**Repository Town N8-S, B:pub.** Original construction **1911**, opening for trade **1912**, so **115 years old in October 2026**. Originally the **Branch Line Hotel**, renamed **The Merged Branch in 2019**. These are **deliberate fictional canon**, not real history, a real NSW hotel licence or a heritage register entry. Exact dates within those years are not invented.

## Evidence-backed era selection

- [Heritage NSW, Tattersalls Hotel: 1911 brick two-storey NSW country hotel](https://apps.environment.nsw.gov.au/dpcheritageapp/ViewHeritageItemDetails.aspx?ID=1590062): contemporary architecture with timber verandahs and corrugated iron roof. This is a comparison, **not** a real record for The Merged Branch.
- [Upper Lachlan heritage study: Gunning's 1916 Telegraph Hotel](https://upperlachlan.nsw.gov.au/wp-content/uploads/2022/12/Heritage-Study-3.pdf): two-storey Federation brick pub. Regional comparator, not the game building.
- [NSW NCC 2022 Amendment 2 applicability](https://www.nsw.gov.au/housing-and-construction/compliance-and-regulation/how-to-comply-national-construction-code): the current code for applicable 2026 new work, not a code that existed in 1911.

**Architectural realism:** a century-old country pub may have older brickwork and newer services. The new façade details echo early Federation country hotels but are not exact surveyed fabric. The game exterior currently looks two-storey while its walk-in interior has **only one room/floor** with a mismatched footprint; this is still open **PUB-CODE/RTPUB-002**. Do not claim upper bedrooms or accommodation as installed or occupied.

**Code realism:** B:pub is now an **existing fictional 1911 building undergoing 2026 works**, not a new building first built in 2026. Use NSW NCC 2022 Amendment 2 for applicable new work and examine existing-building upgrade requirements in relation to the actual scope; do not impose all modern new-build requirements retroactively by assumption. The original *local building rules, original building approval date, DA/CC/OC, Fire Safety Schedule and statutory heritage listing are not evidenced*; the game **must not** invent those official records. Fire safety measures remain subject to the relevant current NSW maintenance and fire safety framework. [NSW AS1851 guidance](https://www.nsw.gov.au/departments-and-agencies/building-commission/industry-changes/as1851-2012/responsibilities-of-building-owners-under-as-1851-2012).

## How the pub fits Repository Town's earlier founding

The pub **did not found the town**: in [Repository Town's canonical history](REPOSITORY_TOWN_HISTORY_1883_2026.md), Reginald and Ellen Repo establish a stores building in **1883** on what becomes G8-N Town Hall. The Branch Line Hotel is built **1911** and opens **1912** on N8-S, eventually becoming The Merged Branch in 2019. The fictional first mayor Reginald Repo served from **1909**, before his invented 1927 knighthood.
