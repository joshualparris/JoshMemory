# JoshMemory Privacy Policy

**Never push personal, family, household, health, tenancy, employment-client, credential, or identifying private information to a PUBLIC repository unless explicitly approved by Josh.**

### What is PRIVATE by default:
* Home or previous residential addresses
* Phone numbers and personal email addresses
* Dates of birth
* Children's identifying information
* Family/private relationship discussions
* Marriage counselling or conflict details
* Health information, diagnoses, symptoms, medications, medical test results and wearable measurements
* Private information about family members
* Tenancy disputes, mould/leak details tied to an identifiable property
* Employer/client/customer information (e.g. Avance IT support details)
* Device serial numbers, account IDs or infrastructure info
* API keys, tokens, passwords, credentials or secrets
* Private Google Drive links or documents
* Anything labelled private, personal, confidential, archive-only or similar
* Detailed personal timelines that combine enough information to identify family or routines

### Separation of Memory
* **`docs/public/`**: Only for material explicitly safe for GitHub (e.g., software architecture, code work, general project milestones).
* **Local Private Storage**: Personal memories must be stored locally outside the repository (e.g., `~/.josh_private_memories/`) and never committed.
