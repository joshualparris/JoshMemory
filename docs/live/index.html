Current architecture

Claude / Codex / Antigravity ↓ existing GitHub authentication JoshMemory storage router ↓ Private GitHub append-only store ↓ Handoffs + project facts + evidence references

Authority rule

JoshMemory is continuity and provenance, not code truth. A resumed agent must check the live repository, branch, HEAD, dirty state and relevant machine/API evidence before acting.

When memory and live evidence disagree, live evidence wins.

Not silently uploaded
